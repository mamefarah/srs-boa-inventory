# M0 Source Request — Documents Needed from BoA / BoFED

This is the minimum evidence package needed before BoA-IMS reproduces official store procedures.

## Request from Bureau Property Administration / Finance & Logistics

Please provide the current approved versions of:

1. Somali Region Stock Management Manual.
2. Somali Region Property Administration Manual/directive.
3. Relevant regional procurement/property proclamation/directive.
4. Goods receipt / stores receipt form.
5. Inspection and acceptance form/certificate.
6. Store requisition form.
7. Store issue voucher.
8. Stock card / bin card.
9. Stock register.
10. Warehouse transfer / dispatch / receipt form.
11. Return-to-store / supplier-return form.
12. Physical inventory count sheet and variance report.
13. Adjustment authorization form.
14. Damaged / expired / obsolete property report.
15. Disposal request, committee and final-disposal forms.
16. Fixed-asset register and custody/handover form.
17. Current approval/signature authority matrix.
18. Mandatory monthly/quarterly/year-end stock reports.
19. Document numbering/copy-distribution rules.
20. Any regional guidance on project/donor-funded stock segregation.

## Metadata required for each document

- official title;
- form/manual number;
- issuing authority;
- approval date;
- effective date;
- revision/version;
- whether currently in force;
- languages available;
- superseded document, if any.

## Important

A photographed/scanned copy is acceptable for M0 analysis. Do not alter original forms for the software yet; first map them exactly, then identify where digital controls can improve the process without changing legal requirements.
