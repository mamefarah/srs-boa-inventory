# M0 Evidence Register — Official Procedure Validation

Status: ACTIVE  
Purpose: distinguish controlling regional evidence from project-specific, federal-reference and non-authoritative material before BoA-IMS workflows are frozen.

## Evidence classes

- **A — Regional controlling:** current Somali Regional State / BoFED / BoA approved rule, directive, manual or official form.
- **B — Regional institutional evidence:** current official regional source showing mandate/responsibility, but not detailed procedure.
- **C — Historical/secondary regional evidence:** useful to identify older regional rules/documents that must be re-obtained and checked for currency.
- **D — Project-specific controlling/supplementary:** DRDIP-II or another project manual governing project-financed goods; not automatically Bureau-wide.
- **E — Federal reference:** federal rule/manual useful for comparison only unless Somali Region adoption/localization is confirmed.
- **F — Reference-only/non-BoA:** NGO/private/template material; never use as official BoA procedure.

## Evidence still required before Bureau-wide workflows are final

1. Current Somali Region Stock Management Manual and approval/version date.
2. Current Somali Region Property Administration Manual/directive.
3. Current regional procurement/property proclamation/directive relevant to inventory.
4. Actual forms currently used by Somali Region Bureau of Agriculture stores:
   - goods receipt / stores receipt;
   - inspection and acceptance;
   - store requisition;
   - store issue;
   - stock/bin card;
   - stock register;
   - warehouse transfer;
   - return;
   - physical-count sheet;
   - adjustment/variance authorization;
   - damaged/expired/obsolete reporting;
   - disposal;
   - fixed-asset/property handover.
5. Current approval/signatory matrix.
6. Current document numbering and copy/distribution rules.
7. Current stock-taking frequency and variance/recount thresholds.
8. Current fiscal closing/reconciliation requirements.
9. Current base-UOM / package-conversion practice.
10. Whether project/funding source restricts consumption of otherwise identical stock.

## Evidence rule

A project manual, federal manual, NGO template or historical report **cannot silently become a Bureau-wide business rule**. Any such adoption must be explicitly confirmed in the process mapping and, where material, an ADR.
