# Pilot Plan

## Scope

Pilot:
- one main warehouse;
- one secondary warehouse;
- selected representative item categories;
- limited trained users;
- real approval roles;
- controlled opening balance.

## Must demonstrate

1. User/warehouse access control.
2. Item master/search.
3. Opening balance import and reconciliation.
4. Receipt + inspection/acceptance.
5. Requisition + approval + reservation.
6. Issue and acknowledgement.
7. Warehouse transfer + destination receipt.
8. Transfer discrepancy.
9. Return/condition change.
10. Blind physical count and approved variance.
11. Adjustment/reversal.
12. Period close.
13. Reports/audit.
14. Backup and restore.
15. Phone usability.

## Scale gate

Do not add more warehouses until:
- no unexplained ledger/projection differences remain;
- internal transfers conserve Bureau totals;
- physical count can reconcile;
- permission bypass tests fail safely;
- backup restore is proven;
- users complete core workflows without support-heavy workarounds;
- high-severity pilot issues are closed or formally accepted.
